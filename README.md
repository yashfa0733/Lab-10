# Lab 10 — University Relational Database
MySQL schema for departments, students, teachers, courses, enrollments and attendance. Includes primary/foreign keys, unique constraints, seed records and 15+ SELECT/UPDATE practice queries with JOIN, GROUP BY, COUNT and attendance percentage.

## Run
1. Start MySQL in XAMPP. 2. Open `http://localhost/phpmyadmin`. 3. Select SQL tab. 4. Copy all of `database/schema.sql` into the query box and click Go. 5. Open `university_portal` and run the report queries individually. Take screenshots of tables, JOIN output, enrollment counts and attendance percentage.

This lab is SQL/database only; it does not yet connect a PHP app.
